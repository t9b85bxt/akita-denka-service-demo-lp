# 秋田電化サービス｜デモLP

福島県郡山市朝日の電器店「秋田電化サービス」向けに制作したホームページのデモ（営業提案用）です。
エアコン・テレビ・冷蔵庫の修理や、家電の買い替え・取付の相談窓口としての導線を想定した1ページ構成のランディングページです。

## 特徴

- HTML / CSS / JavaScript のみの静的サイト（ビルド不要）
- レスポンシブ対応（PC・タブレット・スマートフォン）
- セクション単位のスクロールアニメーション
- 日本語の自然な折り返し（`word-break: auto-phrase` ほか）
- 店舗情報に Google マップを埋め込み

## ローカルでの表示

```bash
python -m http.server 8790
```

ブラウザで <http://localhost:8790> を開いてください。

## 構成

```
index.html          … LP本体（全セクション）
css/style.css        … スタイル
js/main.js           … スクロールアニメーション・モバイルメニュー
images/              … 掲載写真
```

## 注記

- 掲載している写真はイメージです。
- 実績・認証・数値などの未確認情報は掲載していません。
- 本ページは営業提案用のデモであり、依頼者の正式な公開サイトではありません。
